# ⚡ Steel Plant Energy Demand Forecasting: SARIMA vs SARIMAX

Forecasting electricity consumption in a steel plant using time-series analysis, statistical forecasting models, calendar features, and Fourier seasonal features.

## 📌 Project Overview

Electricity demand forecasting is important for industrial energy management, operational planning, and energy efficiency. Steel plants have complex electricity consumption patterns that may vary by hour, day of the week, and season.

This project investigates whether adding calendar and Fourier seasonal features to a statistical forecasting model can improve electricity demand forecasts compared with a seasonal ARIMA baseline.

## 🎯 Objectives

* Analyze historical industrial electricity consumption.
* Explore daily and weekly seasonal patterns.
* Evaluate time-series stationarity using statistical tests.
* Build seasonal-naive and SARIMA forecasting baselines.
* Compare SARIMAX variants using calendar and Fourier features.
* Evaluate forecasts using rolling-origin validation.
* Compare model performance across 24-hour and 168-hour forecasting horizons.

## 📊 Dataset

**Dataset:** Steel Industry Energy Consumption
**Source:** UCI Machine Learning Repository
**Location:** DAEWOO Steel Co., Gwangyang, South Korea
**Original frequency:** 15-minute intervals
**Study period:** 2018

The primary target variable is `Usage_kWh`.

The intended preprocessing step aggregates the original readings into hourly electricity consumption.

Dataset source: [UCI Steel Industry Energy Consumption](https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption)

## 🧠 Forecasting Models

### Baseline Models

* Seasonal Naive — 24-hour seasonal period
* Seasonal Naive — 168-hour seasonal period

### Statistical Models

* SARIMA
* SARIMAX with calendar features
* SARIMAX with Fourier seasonal features
* SARIMAX combining calendar and Fourier features

### Explanatory Features

**Calendar features**

* Day of the week
* Public holiday indicator

**Fourier features**

* Daily seasonal harmonics
* Weekly seasonal harmonics

The models are designed to use predictors known in advance at forecast time. Electrical measurements recorded contemporaneously with electricity consumption are excluded from the forecasting predictors to reduce target leakage risk.

## 🔬 Methodology

1. Load and inspect the original dataset.
2. Parse timestamps and aggregate 15-minute readings into hourly consumption.
3. Explore trends, daily patterns, and weekday differences.
4. Perform stationarity tests and inspect ACF/PACF plots.
5. Fit baseline and statistical forecasting models.
6. Evaluate forecasts using rolling-origin validation.
7. Compare results at 24-hour and 168-hour horizons.
8. Analyze residuals and compare forecast errors.

## 📏 Evaluation Metrics

* **MAE:** Mean Absolute Error
* **RMSE:** Root Mean Squared Error
* **MAPE:** Mean Absolute Percentage Error
* **sMAPE:** Symmetric Mean Absolute Percentage Error
* **WAPE:** Weighted Absolute Percentage Error
* **MASE:** Mean Absolute Scaled Error

Lower values indicate better performance for these error metrics.

## ⚠️ Limitations

* The dataset represents one industrial facility and one calendar year.
* Model performance may not generalize to other steel plants or operating conditions.
* Forecast accuracy depends on correct timestamp handling and validation design.
* Fourier and calendar features may not capture every operational change or unexpected event.
* MAPE can be misleading when actual values are small, so it should be interpreted alongside MAE, RMSE, WAPE, and MASE.
